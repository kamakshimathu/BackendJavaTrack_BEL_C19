# JVM Basics

## What is JDK, JRE, JVM
- JDK (Java Development Kit): toolset for Java developers. Includes compiler (`javac`), debugger, and other utilities needed to build Java applications.
- JRE (Java Runtime Environment): runtime components to execute Java programs. Includes JVM plus libraries but not development tools like compilers.
- JVM (Java Virtual Machine): engine that runs Java bytecode. It interprets or JIT-compiles bytecode into native machine code for your operating system.

## What is bytecode
Bytecode is an intermediate, platform-independent code generated by the Java compiler (`javac`).
- Source code (`.java`) → compile → bytecode (`.class`)
- JVM reads bytecode and runs it on the host machine.

## What does “write once, run anywhere” mean
Java allows developers to write code once and run it on any platform with a compatible JVM. That means you don’t need to recompile for Windows, macOS, or Linux; the same `.class` files can run everywhere the JVM is available.

In short, Java’s cross-platform promise comes from compiling to bytecode and relying on JVM implementations to handle platform-specific execution details.
