# Library Management System Docs

## Overview
This folder contains the supporting documentation for the `library-management-system` project.

## Documents
- `Design_Notes.md`: explains the project structure, OOP concepts, SOLID principles, design patterns, and extension design choices.
- `Testing_Notes.md`: stores user journeys, manual testing notes, final console output, and screenshot placeholders for submission evidence.
- `Class_Diagram.md`: contains the class diagram aligned with the current codebase.

## Suggested Reading Order
1. `Design_Notes.md`
2. `Class_Diagram.md`
3. `Testing_Notes.md`
